# X-Knob 页面与旋钮操作表

Always Ready v3 以方向式开关为默认操作。以下是源码合同；本次改造已烧录并通过镜像写入校验；用户已确认基础开关手感、黑屏直控及按压唤醒正常；多页面与异常场景、电流和续航仍待专项验收。完整规范与 32 项验收见 [Always Ready 记录](always-ready.md)。

按键去抖 25 ms，按下与释放保护各 180 ms，双击窗口 420 ms，长按约 1.2 秒。按住转动需要三档有意位移；电子脸忽略此手势。唤醒按压被吞掉，页面返回时会抑制仍未松开的同一次按压。

主页精调在约 1.8 秒无操作后回电子脸。亮度范围 1–100%，色温范围 2700–6500 K。精调与主页开关使用不同电机模式；关灯不会锁死主页旋转。

## 省电与控灯确认

- 默认 15 秒调暗、45 秒黑屏。POWER 可选调暗 10/15/20/30/45/60 秒，黑屏 45/60/120/180/300/600 秒，黑屏须晚于调暗。有效的旧 NVS 设置会保留。
- DARK 关闭背光、停止面部持续绘制、使电机零输出并禁用驱动；磁角度仍约 100 Hz 采样，Wi-Fi/MQTT 保持在线。RGB 一次灭灯后停止刷新。像素熄灭不等于硬件断电。
- 不自动 Deep Off。USB 与电池采用相同默认策略；VBUS 与电池测量接口没有新增未经验证的推断。
- 手动“关机”独立于自动 DARK：深睡眠时 Wi-Fi/MQTT 和旋转检测停止，不再黑屏直控或接收通知；不向房间灯带发送关灯命令。它采用软件深睡眠并保持原电源锁存，不等于切断电池电源。电源设置中的“自动深睡 / 保持直控”只描述自动待机。
- 手动关机状态保存在 NVS，深睡唤醒先于屏幕、电机和联网初始化检查按键。短按返回深睡眠；长按约 1.2 秒后还需稳定松手 30 ms，启动时吞掉整次按压。关机状态下复位或插拔 USB 也需要长按；首次启动保留原行为。NVS 保存失败时取消关机。
- 此次新增的手动关机与长按开机已通过编译及主机模拟测试，并在完整私有备份、分区核对后烧录，四个写入段均通过哈希校验；尚未完成物理操作验收。应分别检查 USB / 电池下关机、短按、连续短按、长按释放、旋转无效、复位保持关闭及深睡电流。
- 真实 BLE 状态回读须匹配命令 ID 和请求值才确认。State 可以先于 ACK；ACK 自身不构成成功。断线、页面退出、息屏、超时会取消旧 UI 意图，联网后不重播旧命令。
- 黑屏控灯确认仅低亮约 280 ms，失败提示约 320 ms；重要审批提醒约 850 ms。旋转和普通 Codex 事件不唤醒 LCD。

## 场景与 Codex

场景预览不下发命令，单击应用才改变灯带。场景编辑仅保存预设，停止修改约 700 ms 后写入带 CRC 的双槽 NVS；长按或双击先保存，失败时留在编辑页。

Mac 断线不表示灯带断线，也不强迫电子脸呈故障状态。普通工作状态可短暂显示表情，随后恢复陪伴；审批可保持等待表情。默认 Hooks 仅发送重要生命周期事件；Stop 只表示本轮结束，不能声明测试成功。Codex 事件始终只影响旋钮自身，不控制房间灯带。
